¿Qué tan rápido crece cada complejidad?

Mueve n y observa cuántas operaciones hace cada algoritmo. Toca una barra para apagarla.

n = 16 elementos

Barras en escala logarítmica (si fueran lineales, O(2ⁿ) se saldría de la pantalla — justo el punto). Objetivo típico de entrevista: O(n) u O(n log n). Todo lo que sea O(n²) o peor: menciónalo y optimiza.

Pregúntate: con n = 64, ¿cuántas veces más lento es O(n²) que O(n)? ¿Y O(2ⁿ)?
